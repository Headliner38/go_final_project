**Описание проекта:**
ToDo API – серверное приложение для управления задачами с аутентификацией и REST API.

**Основные возможности:**
- Добавление, редактирование, удаление и получение задачи.
- Отметка задач как выполненных.
- Автоматический расчет следующей даты.
- Хранение данных в SQLite

**Реализованные дополнительные возможности:**
- Запуск сервера на порте, определенном в переменной окружения.
- Определение пути к файлу базы данных через переменную окружения.
- Поиск задач по оглавлению, комментарию и дате.
- JWT-аутентификация с проверкой токена в куках.

**Переменные окружения:**
- TODO_PORT - порт для сервера.
- TODO_DBFILE - путь к файлу с базой данных.
- TODO_PASSWORD - пароль для авторизации.


**Структура проекта:**
- pkg/api/ - обработчики API, middleware и дополнительные функции для реализации работы обработчиков
    - api.go - HTTP - API для управления эндпоинтами. Некоторые эндпоинты требуют авторизации.
    - addtask.go - обработчики для получения, добавления, редактирования, удаления задач и вспомогательные функции.
    - authMiddleware.go - middleware для проверки JWT-токена из куков.
    - checkdate.go - содержит функцию для проверки даты на правильный формат.
    - doneHandler.go - обработка выполнения задачи.
    - nextdate.go - содержит функцию для получения следующей даты и обработчик для следующей даты.
    - search.go - реализация возможности поиска конкретной задачи.
- pkg/api/auth/ - генерация jwt-токенов и проверка их валидности.
    - keys.go - создание RSA ключей для подписания jwt-токена.
    - tokenAndHash.go - содержит функцию для создания jwt-токена и функцию для проверки валидности jwt-токена.
- pkg/db/ - работа с базой данных задач.
    - db.go - инициализация базы данных.
    - task.go - вспомогательные функции для обработчиков, получающие задачи из БД.
    - taskSearch.go - содержит функцию для поиска задачи в БД по оглавлению или комментарию, а также функцию для поиска задачи по дате.
- pkg/server/ - реализация запуска сервера.
    - server.go - запуск сервера.
- tests/ - тесты для проверки проекта.
- web/ - frontend проекта.
- go.mod - файл с описанием модуля Go.
- go.sum - файл с хешами зависимостей для проверки их целостностей.
- main.go - главный модуль приложения. Инициализирует: RSA ключи для аутентификации, подключение к базе данных и запускает HTTP - сервер.
- scheduler.db - база данных с задачами. Используется SQLite.

**Выполненные задания повышенной трудности:**

- Определение пути к файлу базы данных через переменную окружения.
- Поиск задач по оглавлению, комментарию и дате.
- JWT-аутентификация с проверкой токена в куках.

**Инструкция по запуску кода локально:**

Выполните в терминале команду - "go run main.go".

**Инструкция по запуску тестов:**

**Важно!!!**

Для получения токена для тестов Вам необходимо:
1)Запустить сервер
2)Перейти на страницу авторизации(http://localhost:7540/login.html)
3)После ввода пароля на странице авторизации, в консоли высветится токен, скопируйте его.
4)Вставьте его в файле settings.go в переменную Token.
5)Запустите тесты.

Выполните в терминале команду - "go test ./tests".

Если все тесты выполнились без ошибок Вы увидите:
- ok

В случае возвращения тестом ошибки Вы получите текст с описанием ошибки.
